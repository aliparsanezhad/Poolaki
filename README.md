# 🪙 پولکی (Poolaki) - شبیه‌ساز دقیق و کاملاً کاربردی

کلون دقیق، تعاملی و کاربردی از اپلیکیشن مدیریت مالی و حسابداری شخصی **«پولکی» (Poolaki)** مطابق با ۱۰ اسکرین‌شات اصلی برنامه، پیاده‌سازی شده با **React 19**، **Tailwind CSS v4**، **Vite** و **Lucide Icons** همراه با فونت **وزیرمتن (Vazirmatn)** و استایل تیره (Dark Theme).

---

## ✨ ویژگی‌های پیاده‌سازی‌شده (مطابق اسکرین‌شات‌ها)

1. **داشبورد و تراکنش‌های اخیر (صفحه اصلی - `photo_5`)**:
   - نمایش لیست تراکنش‌های اخیر به تفکیک تاریخ خورشیدی (اردیبهشت ۱۴۰۵)، دسته‌بندی و مبالغ.
   - محاسبه خودکار مجموع کل موجودی، جمع دخل و خرج ماهانه.
   - دکمه شناور `+` (FAB) در گوشه چپ پایین با انیمیشن چرخش برای ثبت تراکنش.

2. **ثبت تراکنش جدید (`photo_4`)**:
   - انتخاب نوع تراکنش: **خرج** / **دخل** / **جابجایی**.
   - فیلد مبلغ بزرگ با فرمت سه‌رقم‌سه‌رقم به تومان.
   - انتخاب کارت/منبع پرداخت (کارت تجارت، ملی، نقدی).
   - تاریخ شمسی (امروز و روزهای قبل).
   - چیپ‌های سریع دسته‌بندی (`بنزین`، `ابزار نقره`، `متفرقه`).
   - اتصال به دراور انتخاب دسته‌بندی با نقطه قرمز اعتبارسنجی.

3. **انتخاب سلسله‌مراتبی دسته‌بندی‌ها (`photo_3`)**:
   - باتم‌شیت دسته‌بندی‌ها با قابلیت باز و بسته شدن زیرمجموعه‌ها.
   - آیکون مداد برای پرش مستقیم به ویرایش دسته‌ها.

4. **مدیریت دسته‌بندی‌ها (`photo_2`)**:
   - تفکیک دسته‌های خرج و دخل.
   - دستگیره مرتب‌سازی (`=`) و دکمه افزودن.
   - امکان افزودن دسته‌بندی جدید.

5. **ویرایش پیشرفته دسته‌بندی و زیرمجموعه‌ها (`photo_1`)**:
   - آواتار کارت بزرگ با آیکون و رنگ اختصاصی.
   - پالت انتخاب رنگ و تغییر آیکون دسته.
   - مدیریت لیست زیرمجموعه‌ها (اسنپ‌فود، رستوران، کافه، متفرقه، کترینگ یاس، BoysNight) همراه با حذف و افزودن.

6. **سررسید، چک و اقساط وام (`photo_6`)**:
   - کارت‌های خلاصه سررسید (کل، پرداخت شده، معوق).
   - تایم‌لاین رویدادها با شمارنده روز (مثلاً وام خرید کالا ۲۹ اسفند ۱۴۰۴ - پرداخت‌شده).
   - فیلترهای «یادداشت / چک / قسط».
   - امکان تغییر وضعیت به پرداخت‌شده با یک کلیک.

7. **مدیریت کارت‌ها و حساب‌ها (`photo_7` & `photo_8`)**:
   - تشخیص خودکار نام بانک از روی ۱۶ رقم شماره کارت (BIN Detection).
   - نام مستعار کارت.
   - فعال‌سازی خودکار خواندن پیامک بانکی.
   - تنظیم سرشماره‌های بانکی مجاز (مثلاً `TejaratBank`).
   - فیلد موجودی اولیه کارت.

8. **شبیه‌ساز هوشمند پیامک بانکی (`photo_9`)**:
   - ابزار اختصاصی برای ارسال یا الصاق متن پیامک‌های واقعی بانک‌های تجارت، ملی، ملت، صادرات و...
   - استخراج خودکار مبلغ، نوع تراکنش، نام بانک و ثبت آنی در تراکنش‌ها بدون ورود دستی.

9. **پشتیبان‌گیری و مدیریت داده‌ها (`photo_10`)**:
   - خروجی فایل پشتیبان با پسوند اختصاصی `.plk` و دانلود فایل.
   - بارگذاری و بازیابی (Restore) فایل پشتیبان `.plk` یا `.json`.
   - شبیه‌سازی اتصال به Dropbox.
   - دکمه حذف کامل اطلاعات (Reset).

10. **قالب دوگانه (Dual View Mode)**:
    - **نمای گوشی موبایل (Phone Frame)**: دارای قاب گوشی پرچمدار اندروید، استاتوس‌بار OneUI، پانچ دوربین و کلیدهای ناوبری سیستم.
    - **نمای تمام‌صفحه (Responsive)**: برای کارکرد راحت روی مانیتورها.

## 🚀 نحوه اجرا

```bash
# نصب پکیج‌ها (قبلاً انجام شده)
npm install

# اجرای سرور توسعه
npm run dev

# ساخت بیلد نهایی
npm run build
```

آدرس سرور لوکال: **`http://localhost:5173/`**
