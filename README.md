# 🛡️ جیب‌یار (JeebYar) - دستیار هوشمند مالی و مدیریت ثروت شخصی
> **نسخه پیشرفته و بازطراحی‌شده بر پایه پولکی (Poolaki Super-App Edition)**  
> طراحی شده با **React 19**، **Tailwind CSS v4**، **Vite**، **Lucide Icons** و استایل دارک مدرن با فونت **وزیرمتن (Vazirmatn)**.

---

## 💎 درباره جیب‌یار (JeebYar)

**جیب‌یار** نسل جدید نرم‌افزارهای مدیریت مالی شخصی (PFM) در ایران است. این پروژه نه‌تنها تمامی قابلیت‌های نسخه اصلی **پولکی (Poolaki)** و آخرین آپدیت‌های تلگرام آن را به‌طور دقیق و تعاملی در خود جای داده، بلکه با افزودن امکاناتی چون **هوش مالی AI**، **صندوق سرمایه‌گذاری طلا و کریپتو**، **اسکنر فاکتور**، **محاسبه‌گر دنگ گروهی** و **سیستم جامع اشتراک ویژه**، به یک پلتفرم جامع مدیریت ثروت تبدیل شده است.

---

## 🚀 ویژگی‌های کلیدی جدید جیب‌یار

### ۱. 💎 سیستم اشتراک تعاملی (Subscription Paywall)
- سه سطح کاربری:
  - **پایه (Free)**: ثبت دستی و پایش پایه حساب‌ها
  - **پیشرفته (PRO ماهانه/سالانه)**: فعال‌سازی OCR، پایش دارایی و گزارش‌های تحلیلی
  - **وی‌آی‌پی نامحدود (VIP Lifetime)**: دسترسی دائمی به هوش مصنوعی و اولویت پارس پیامک
- پشتیبانی از کد تخفیف با بررسی آنی (کد تست: `JEEBYAR50` با ۵۰٪ تخفیف)
- درگاه پرداخت امن شبیه‌سازی‌شده (بانک سامان / شاپرک)
- افکت پیروزی و پرتاب کانفتی (`canvas-confetti`) پس از فعال‌سازی اشتراک
- ذخیره‌سازی وضعیت اشتراک در `LocalStorage`

### ۲. 🧮 ماشین‌حساب درون‌برنامه‌ای فرم تراکنش (مشابه آپدیت تلگرام پولکی)
- کیپد ریاضی مستقیم روی صفحه ثبت تراکنش با کلیدهای `+`, `-`, `×`, `÷`, `%`
- ارزیابی فرمول‌های حسابی در لحظه (مثلاً `250000 + 40000`)
- دکمه‌های درج سریع سه صفر (`000`)، پیست از کلیپ‌بورد و پاک‌کردن تک‌رقمی
- انتقال خودکار و بدون خطای حاصل محاسبه به فیلد مبلغ نهایی

### ۳. 📥 صف پیامک‌های انباشته و ثبت دسته‌جمعی (Batch SMS Import)
- نمایش کارت پیامک‌های خوانده‌نشده روی داشبورد با برچسب هشدار
- دراور اختصاصی پیامک‌های تجمیعی با دکمه **«ثبت همه با هم»**
- اختصاص خودکار به دسته پیش‌فرض **«تعیین‌نشده»** جهت تفکیک سریع در فرصت مناسب
- محاسبه آنی و اصلاح موجودی حساب‌ها به صورت خودکار

### ۴. 🔔 نوتیفیکیشن تعاملی ۱-کلیک (Interactive Android Notification)
- بنر واقع‌گرایانه نوتیفیکیشن اندروید با اسلاید از بالای صفحه گوشی
- چیپ‌های دسته‌بندی سریع (مثلاً *کافه*، *سوپرمارکت*، *تاکسی*) مستقیماً درون بنر
- امکان ثبت فوری دسته‌بندی با یک کلیک بدون باز کردن فرم‌های طولانی

### ۵. 🏦 پشتیبانی اختصاصی از بانک مسکن (Bank Maskan)
- تشخیص شماره کارت با پیش‌شماره BIN `628023`
- تحلیل الگوی پیامک‌های مانده و برداشت/واریز بانک مسکن با نام کارت پیش‌فرض

### ۶. 🪙 صندوق ارزش‌گذاری لحظه‌ای طلا، سکه و تتر (Asset Valuation Vault)
- پایش لحظه‌ای مظنه طلای ۱۸ عیار، آبشده، سکه امامی و نقره
- نگهداری موجودی تتر (USDT) با نرخ روز دلار آزاد
- محاسبه لحظه‌ای ارزش خالص سبد دارایی‌ها به تومان

### ۷. 🧾 اسکنر هوشمند رسید و فاکتور (AI Receipt OCR Scanner)
- اسکن و پردازش خودکار رسیدهای کاغذی کارتخوان (POS) و اسکرین‌شات اپ‌های بانکی
- تشخیص خودکار مبلغ، تاریخ، نام فروشگاه/پذیرنده و شماره کارت مقصد
- تبدیل رسید با یک کلیک به تراکنش نهایی با طبقه‌بندی هوشمند

### ۸. 👥 ماشین‌حساب دنگ گروهی (Split Bill Manager)
- مدیریت دورهمی‌ها، سفرها و رستوران
- محاسبه دقیق سهم هر فرد، وضعیت تسویه‌شده/بدهکار
- تولید خودکار متن شکیل دنگ آماده کپی برای گروه‌های تلگرام و واتساپ

### ۹. 🧠 کارت هوش و سلامت مالی (Financial Health Score)
- امتیاز سلامت مالی (مثلاً ۸۸ از ۱۰۰) بر اساس نرخ پس‌انداز و پایداری درآمد
- محاسبه میزان بقای مالی (Burnout Runway) بر حسب تعداد ماه‌های تاب‌آوری
- دسترسی سریع به ابزارهای پرکاربرد از بالای داشبورد

## 📱 قابلیت‌های میراثی کلون دقیق پولکی (Poolaki Core)

- **صفحه اصلی و جریان نقدینگی**: موجودی کل، دخل و خرج ماهانه، جستجوی زنده در تراکنش‌ها
- **مدیریت عمیق دسته‌بندی‌ها**: ایجاد، ویرایش، پالت رنگ، آیکون و زیرمجموعه‌ها (رستوران، اسنپ‌فود و...)
- **سررسید و اقساط**: یادداشت، چک و اقساط با تقویم خورشیدی و وضعیت وصول
- **کارت‌ها و حساب‌ها**: تشخیص خودکار BIN بانک‌های ملی، ملت، صادرات، تجارت، بلوبانک، سامان، مسکن و...
- **پشتیبان‌گیری اختصاصی PLK**: دانلود خروجی `.plk` و بازیابی کامل اطلاعات با درگ و دراپ
- **شبیه‌ساز پیامک بانکی**: امکان تست پیامک‌های متنی با پارسر قدرتمند RegEx
- **نمای دوگانه Responsive**: سوییچ بین نمای گوشی موبایل پرچمدار و نمای دسکتاپ تمام‌صفحه

## 💻 راه‌اندازی و اجرا

```bash
# کلون پروژه
git clone https://github.com/aliparsanezhad/Poolaki.git
cd Poolaki

# نصب وابستگی‌ها
npm install

# اجرای سرور لوکال با قابلیت Hot Reload
npm run dev

# ساخت بیلد نهایی و بهینه‌سازی شده
npm run build
```

پس از اجرا، پروژه روی آدرس پیش‌فرض `http://localhost:5173/` در دسترس خواهد بود.
